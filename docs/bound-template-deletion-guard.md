# 綁定範本刪除保護與文件設定

文件與報告設定的「目前使用」標示移到「電子簽章設定」收合標題右側，使用已儲存的伺服器狀態；只選取尚未儲存的方式不會改變標示。手機不足寬度時允許換行。三個收合區塊保留原有草稿、鍵盤與權限行為。此頁移除「資料來源與整合狀態」及「管理中心設定維護」兩個附加欄位，其他管理模組維持原入口。上傳報告按鈕及視窗名稱改為「報告單範本」。

委託單與報告單的目前綁定版本不能刪除。報告單先從「管理綁定」選擇「解除綁定（保留舊案件版本）」並儲存，才能刪除；委託單可改綁其他原稿或改用系統內建空白委託單後再刪除原版本。目前作為預設的內建委託單也受到保護。已開啟刪除確認時若其他操作重新綁定，後端仍會拒絕刪除；不自動解除、不換綁其他文件。

052_bound_template_deletion_guard.sql只更新兩個既有刪除函式。報告刪除沿用租戶／管理權限、工作區與試驗鎖、操作指紋、版本檢查與收據；取得鎖後若原稿仍被綁定，回傳TRIAL_TEMPLATE_IN_USE（HTTP409）。新刪除只退役未綁定原稿，回傳unbound=false。既有成功操作的收據仍可查詢與重讀，未知寫入不得重送。空白委託單沿用TEMPLATE_IN_USE，補足系統內建預設版本的保護。直接表格與舊函式權限不開放。

刪除未綁定原稿仍保留實體報告檔、已送簽案件及固定儲存格快照。安裝不刪檔、不改綁、不改案件；雲端先回滾驗證，再在交易內核對既有資料指紋、非相關函式／權限及public schema。已安裝遷移不能重播。
