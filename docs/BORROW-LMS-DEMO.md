# 借用與 LMS 設備同步

申請借用頁與新增委託單頁均為單一新增按鈕入口，表單使用共用浮動視窗。申請借用頁不重複顯示歷程列表，借用紀錄集中於「我的委託/借用 → 借用單」。

## 設備來源與狀態

- 下拉選單直接讀取 LMS 的 dqa-equipment-demo-v1 台帳，以 equipmentId 綁定，顯示編號、名稱與目前狀態，另提供型號、序號及位置。LMS 改名後清單會反映新名稱，送出與核准再讀取最新台帳；未建立設備時不提供假選項。
- 每筆借用對應一台有獨立編號的實體設備，數量為 1。需要多台時分別提出各設備申請，不將試驗樣品容量當成設備台數。
- 送出仍為待核准，不立即改設備狀態。沿用原有的一階主管／系統管理員核准權限及禁止自審。
- 核准時設備必須仍為待機，且借用期間（含歸還日）無試驗保留衝突；準備／清理緩衝、目前占用與暫停保留均列入檢查。
- 核准後設備立即顯示「借用」，保留借用單號、借用人、預計歸還與操作紀錄。「我的借用單」將已核准顯示為借用。借用中的設備無法加入試驗排程；即使已存在排程到期，生命週期也不會把借用設備變成試驗使用中。
- 日期是預計借用／歸還日期；目前 Demo 採核准即鎖定設備，並不等到未來借用日才鎖定，也不按預計歸還日自動釋放，避免尚未實際歸還卻被排程。

## LMS 確認歸還

LMS 設備管理 → 設備資訊 → 狀態變更，借用設備僅能選擇待機中，填寫確認結果後由一階主管或系統管理員確認。設備恢復待機、借用單標為已歸還，兩者保留操作者與時間歷程。舊視窗若對應的借用單已改變會拒絕操作，避免誤歸還另一筆借用。

核准與歸還使用現有可復原交易 journal 同步設備與借用資料，儲存中斷可恢復，避免只改一側。清除重設會一併釋放有借用單連結的借用設備，維護中的設備不受影響。

舊版借用申請只有名稱時，僅於名稱在台帳唯一匹配時允許核准並綁定編號；已核准的舊資料不自動補造設備占用紀錄。名稱無法對應、設備已移除或數量大於一台時，需重新選擇設備提出申請。

此同步僅在同一瀏覽器的 Demo 儲存資料間進行；不同瀏覽器或裝置沒有後端同步。未連正式公司系統或實機。
