# PR49 財務、報表與共用版面

## 共用規則

- 每個獨立頁面標題以 60px 最小高度、上下 12px 間距及垂直置中排列；窄畫面允許工具按鈕換行，對話框維持原版面。
- 主頁籤 42px、一般操作 36px，內層頁籤保留原來的底線樣式。列表與表頭貼齊所屬框格左右邊緣；窄畫面在表格容器內捲動。
- 設備狀態操作沿用藍底設備資訊 SVG；資訊、紀錄、編輯、下載等列表操作顯示圖示，以 title／aria-label 提供名稱。JSX 群組不另算表格欄位。
- 實驗室設備／物料及電子委託頁的操作訊息放在頁面標題下方，保留原錯誤、待確認與重試操作。

## 財務

右上角新增成本／憑證，移除重新讀取。搜尋條件、符合筆數與分頁同時收合，篩選條件於按套用後提交。來源可以選取既有資料或貼完整識別碼，日期及識別碼先驗證。列表拆開分類、帳務類型、費用性質、次數、金額與說明，字體 14px。完整紀錄 ID 仍可複製以關聯憑證。

篩選統計與年度概覽改為兩張卡片；各幣別、預估／實際、內部／外部分組，不合併不相容金額。年度只按年及專案，未估金額與作廢規則保留。037 僅新增費用性質讀取條件，先篩選再分頁／計算筆數與合計；不更動既有計價與寫入 RPC。

## 報表與範本庫

移除五個領域功能方塊，保留六類既有報表。頁籤右側搜尋與篩選可在桌面及手機收合，收合後條件仍生效並顯示數量。顯示／匯出設定整理為緊湊區塊，保留偏好儲存、欄位勾選、至少一欄及 Excel／PDF 的既有流程。

三個系統共用同一份範本表格：名稱、分類、版本、試驗工時／對應項目、圖示操作。內層分類維持原頁籤；範本預覽、下載、詳細資料、來源核對與分頁功能保留。

## 發布範圍

同一個 PR49 提供私人 Vercel Preview。Preview 使用既有原生 Supabase／AI 後端與原系統登入；使用者儲存會寫入共用資料庫。程式尚未合併或部署到 Production。增量 037 已在共用資料庫提交並讀回，交易檢查確認既有業務／私人資料、無關函式／ACL 與 public 定義未變更；未建立真人財務測試資料。

瀏覽器截圖採示意 API，寫入操作僅作用於測試替身；SQL 驗證使用隔離本機資料庫且回滾測試資料。未代替使用者登入遠端網站或操作正式案件。
