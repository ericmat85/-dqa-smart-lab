# 報告範本刪除與委託單綁定視窗

文件設定保留空白委託單與報告原稿的上傳、預覽、版本列表、綁定及資訊代入。委託單的綁定表單改由列表／標題列的鏈結圖示開啟浮動視窗，包含目前版本、來源選擇、預覽與「委託資訊代入自動化」。選擇來源後須明確儲存；取消不改綁，未知結果只查詢原操作。

移除文件設定的「內建試驗參考範本」區塊與「新增空白報告單」按鈕；不執行既有參考資料刪除。報告單只從上傳原稿建立版本，仍依試驗綁定。設定頁與浮動視窗不提供下載，資料庫仍提供可用原稿下載。

報告原稿的操作列新增紅色刪除圖示。確認視窗顯示檔名、版本與影響：目前版本刪除時同一交易解除綁定並增加修訂；歷史版本刪除保留目前綁定。原稿從可用清單移除，禁止重新綁定及直接讀取；已送簽案件仍使用原固定版本與欄位對應。刪除不會自動套用另一份範本。

051 新增私有移除紀錄表、刪除 RPC，並擴充目錄／綁定／直接讀取函式。表啟用 RLS，anon、authenticated、service_role 均無直接資料權限，移除紀錄不可覆寫或撤銷。操作限定目前工作區具 catalog.manage 的帳號，沿用操作識別與結果收據，拒絕跨工作區、過期綁定修訂及不同內容重用操作。刪除與綁定／送簽共用試驗鎖；原稿與既有案件快照保留。舊儲存收據重讀不會把已刪除原稿重新綁回。

安裝只新增空紀錄表及受權限保護的函式，不會刪除任何實際原稿、改動現有綁定或既有案件。雲端安裝交易先核對 050 基準、所有既有資料指紋、非相關函式及 public schema；先回滾驗證，再單次安裝與讀回。功能測試使用本機合成資料與 API fixtures，未替使用者刪除範本。

驗證：36 項桌面／手機／320px／深色／1920px 瀏覽器案例、167 項程式／API測試、77 項隔離 PostgreSQL 測試通過。瀏覽器為新流程 12、尺寸補強 6、既有回歸 18；回歸中兩項舊按鈕名稱的斷言更新後分批重驗通過。Build、diff 通過；Lint 0 錯誤、105 個既有警告。051 已單次安裝並讀回驗證；既有資料與綁定保持原內容，移除紀錄表為空。
