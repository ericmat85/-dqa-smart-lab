# 文件預覽與品牌設定精修

文件頁的品牌、電子簽章、文件範本自動化編輯器三區均預設收合。收合仍保留草稿及已讀資料。品牌摘要顯示已載入修訂或共用資料未儲存狀態。

管理總覽白色面板只包標題與工作區主視覺，下方管理卡片回到頁面背景。管理頁籤取消選取狀態的底線，保留鍵盤焦點外框；寬度足夠顯示整列，溢出時出現左右捲動鍵，也可觸控捲動、鍵盤左右／Home／End到達所有頁籤。

報告標題、說明、下載操作與兩類歷程摘要使用相同文字起點。自動化圖示採實心藍色星形；綁定鏈結為一個藍色實心、一個白色內襯的鏈環，停用狀態保持淡化。

品牌新增報告標題、中英雙語、主題色、字型／字級、A4方向、抬頭對齊、密度、浮水印、頁尾與頁碼選項，以及兩頁合成全視窗預覽、HTML下載、列印及縮放。版面選項只作試排，不改寫已上傳的Excel。實驗室抬頭、地址及聯絡資料可透過既有共用profile API與修訂保護儲存；唯讀權限不提供共用資料編輯，原有未知寫入保護保留。

依本次需求，預覽下載政策取代先前「設定與唯讀預覽不提供下載」的UI限制。三系統共用Excel預覽上方提供下載原檔、列印目前工作表、縮放、工作表選單與鍵盤頁籤；移除底部關閉列，上方關閉與Esc保留。預設符合頁寬以放大內容，另保留適合整頁及25–300%比例。各操作仍經原本的讀取器及權限檢查，失效或無權讀取時停止；未更動後端授權。簽核中嵌入的報告檢視可開啟相同全視窗工具。

結案PDF預設符合頁寬，維持全視窗並新增頁面切換及列印目前選取頁；從已驗證PDF渲染頁面產生列印內容。原始PDF下載、縮放與上方關閉保留，讀取失敗不提供文件。品牌合成預覽下載明示HTML，原稿下載保留原Excel／PDF類型，不冒稱正式報告。

本次不修改schema、文件綁定、簽章權限或既有案件。遷移至052已安裝，不得重播。

驗證使用合成帳號、Excel及PDF資料；列印測試攔截瀏覽器列印呼叫，檢查實際列印內容及清理，未向實體印表機送件。預覽下載比對原稿內容與雜湊，品牌HTML另驗證輸出文字。此輪不重跑SQL，保留052的綁定刪除保護。

60項不同瀏覽器案例通過，含分批複測；涵蓋桌面／手機320、390、1280、1920px、深色模式、三系統Excel／PDF、頁籤捲動、圖片縮放對齊、列印清理、原檔下載、品牌抬頭及綁定刪除保護。16項Node／API測試、Build、diff通過；Lint 0錯誤、105個既有警告。未更動schema或實際業務資料。
