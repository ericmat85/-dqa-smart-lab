# 登入面板瘦身與直角調整

依使用者提供的電子委託登入截圖，縮窄共用右側登入面板並移除左上、左下圓角，再依標註箭頭將面板左移、表單上移。套用電子委託、LMS、Lab 與 DQA 展示入口，深淺色一致。

- 桌面面板依視窗寬度取 34%，最窄 360px、最寬 520px；721–1000px 視窗使用 350px 面板。
- 桌面面板右側保留 `clamp(24px, 5vw, 96px)` 的實驗室背景窄條，1920px 時為 96px；表單由垂直置中改為距面板頂部約 56px。手機不加側邊留白。
- 1920px 視窗實測：面板由約 784px 調整為 520px，左上及左下圓角均為 0px。
- 左側底部四個功能圖示改為靠左群組排列，桌面間隔 24–56px；中型視窗 24px，寬度不足時換行，避免英文文字擠在一起。
- 手機維持單欄全寬，移除圓角及原先向上覆疊 10px 的樣式，品牌區與登入區平直接合。
- 產品樣式僅修改 `src/EnterpriseLogin.css`，並更新既有登入排版測試以檢查右側窄留白及表單頂部位置；登入驗證、帳號、角色及欄位功能沿用既有實作。
