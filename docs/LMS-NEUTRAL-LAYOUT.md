# LMS 桌面版框架與灰色互動樣式

排程頁原本為右側浮動 AI 助理預留額外空間，導致主框架比試驗委託頁窄。現在兩頁使用相同的內容邊距與可用寬度；AI 助理移至頂部工具列，保留原有功能，不再佔用表格右側空間。

本次樣式僅限 LMS：中灰色側邊欄、灰色主要按鈕、淺灰色 hover 外框，以及沒有 hover 外框的個人帳號按鈕。Logo 沿用透明圖片，以顯示濾鏡將字樣轉白並保留紅色標誌，縮至 170px、靠左。其他入口的 Logo 與主題色不變，狀態及危險操作保留語意顏色。

回歸涵蓋排程與委託頁框架寬度一致、長名稱換行、54 筆排程分頁、依執行人員檢視、編輯排程、收合側邊欄，以及 AI 按鈕不遮擋表格操作。主題測試涵蓋四入口的登入頁，以及 LMS 深淺色互動、個人設定和上傳照片按鈕。
