# LMS 桌面版框架與灰色互動樣式

排程頁原本為右側浮動 AI 助理預留額外空間，導致主框架比試驗委託頁窄。現在兩頁使用相同的內容邊距與可用寬度；AI 助理以 40px 小按鈕放在右下獨立工具列；內容區在工具列上方捲動，保留完整表格寬度，也避免浮動按鈕遮住任何一列。

本次樣式僅限 LMS：中灰色側邊欄、灰色主要按鈕、淺灰色 hover 外框，以及沒有 hover 外框的個人帳號按鈕。Logo 沿用透明圖片，以顯示濾鏡將字樣轉白並保留紅色標誌，縮至 170px、靠左。其他入口的 Logo 與主題色不變，狀態及危險操作保留語意顏色。預設頭像統一淡紫底，排程圖表按鈕為灰底白字及白色圖示，已選取的排序欄位使用藍紫色（深色模式另有對應底色）。

AI 對話按時間順序向下累積，回答逐字呈現時僅捲動助理內容區。選擇常見問題會收合題庫、聚焦新對話並捲到新內容；一般輸入送出則保留輸入框焦點。對話保留在當次 LMS 工作階段，不再以列表分頁將第 21 筆新對話藏到下一頁。

試驗委託的待審查、待核准、待審核改用與排程頁一致的分頁籤，保留全部委託。分類筆數與列表來自同一份案件集合，搜尋可與分類及分頁組合；切換分類會重設頁碼。分頁籤支援方向鍵、Home、End、焦點移動及選取狀態。

淺色模式的主內容背景改為淺灰；儀錶板上方的同步提示與資料提醒入口移除，資料更新沿用原有訂閱機制。側欄各功能與登出使用統一的白色 SVG 線條圖示，AI 按鈕改用第二主題色紫色（#7c3aed）。

回歸涵蓋排程與委託頁框架寬度一致、長名稱換行、54 筆排程分頁、依執行人員檢視、編輯排程、收合側邊欄，以及 AI 按鈕不遮擋表格操作。主題測試涵蓋四入口的登入頁，以及 LMS 深淺色互動、個人設定和上傳照片按鈕。
