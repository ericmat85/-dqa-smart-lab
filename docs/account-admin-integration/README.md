# 系統管理與帳號權限整合

## 介面與導覽

- LMS 側欄、首頁標題、模組返回及麵包屑由「系統設定」改為「系統管理」，同步角色權限的顯示名稱及英文介面。
- 移除側欄獨立的帳號管理入口；由「系統管理 → 帳號與權限管理」直接進入既有帳號清單／角色與權限介面，移除原模組重複的唯讀摘要及二次導覽。
- 直接沿用原 AccountManagement、RoleSettings、帳號新增／編輯／刪除、內建與自訂角色編輯對話框；不建立第二套帳號資料或編輯器。
- 單層頁面外框，返回系統管理與新增帳號並排，手機可換行。保留緊湊統計列、搜尋篩選、帳號／角色頁籤。
- 新位置 `/lms/settings/accounts`；舊 `/lms/accounts` 相容導向。網址與權限鍵仍保留 settings，避免舊偏好、角色資料或入口失效。

## 權限與資料

原 `canManageAccounts` 為帳號操作依據。原有只具帳號管理權、未具 settings 頁權的自訂角色可由側欄「系統管理」直接進入帳號模組，但不能開啟其他系統管理模組或修改其設定。移除帳號管理權後立即拒絕操作及直接網址。

其餘系統管理功能仍沿用原 settings／模組權限。未賦予系統管理員業務簽核權；九階狀態機、禁止自審／跨階、帳號資料格式及權限儲存鍵不變。

- Lint、Production Build、diff check 通過；既有大型 chunk 提示仍存在。
