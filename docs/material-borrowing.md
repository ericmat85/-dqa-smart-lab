# 設備與物料借用

依使用者確認，本次新增「物料借用，需歸還」，沿用既有瀏覽器 Demo 的主管核准流程。未加入耗材領用或不歸還流程。

## 操作方式

1. 電子委託 → 申請借用，選擇「借用類別：設備／物料」。設備仍為每筆一台，物料可輸入正整數數量，顯示 LMS 台帳的可用數量與單位。
2. 填寫用途、借用日及預計歸還日後送出。此時僅建立待核准紀錄，不扣庫存。
3. 由未參與申請的一階主管或系統管理員在 LMS 審查核准；重新檢查物料狀態、單位與即時可用量，核准才扣除可用數量。庫存不足則保留待核准，不會超借；退回不扣庫存。
4. LMS → 物料管理 →「借出物料／歸還」，由有權限的主管確認全數歸還並填寫清點結果，補回可用數量。委託者借用清單同步顯示「已歸還」。本次不提供分批歸還。

借用與歸還皆保留操作紀錄。多筆借用獨立計量，歸還其中一筆不會清除其他借用。物料借用不佔設備排程，也不改設備台帳。舊設備借用紀錄無需轉換。

## 庫存與資料保護

- 台帳與借用紀錄使用既有 lifecycle transaction journal 一起更新，儲存中斷後可恢復，避免重複扣量或補量。
- 借出期間禁止直接修改總量、可用量或單位；舊編輯視窗遇到庫存已變更時拒絕覆寫，需重新開啟。
- Demo 案件重設清除借用前先釋放已核准的物料數量；保留物料台帳，資料不一致則阻止重設。
- 仍使用既有瀏覽器本機資料，並非新增伺服器庫存服務。待核准申請不預留庫存，以核准當下可用量為準。

## 實作與驗證

核心新增 `materialBorrowing.mjs`、`BorrowResourceFields.jsx`、`MaterialBorrowReturns.jsx`；整合既有申請、主管審查、物料台帳、借用清單、重設與中英文介面。

- 單元測試 195／195 通過，含物料借用的數量、日期、權限、庫存重檢、多筆歸還、重複操作、單位變更、中斷恢復及案件重設。
- 正式建置跨系統驗收 47／47 通過，含新增三項物料流程測試、既有跨系統深淺色／手機／英文大字體與權限檢查。
- 新增瀏覽器測試確認完整流程：可用 5 組 → 申請 3 組仍為 5 → 核准後 2 → 歸還後 5；手機超量申請被阻止；舊編輯視窗不可覆寫已更新庫存。
