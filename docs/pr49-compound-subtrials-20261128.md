# 複合試驗的子試驗編輯

在「共用試驗項目與方法」新增或編輯試驗項目，選擇「複合型連續試驗」或「複合型非連續試驗」，即可直接編輯子試驗。原「複合型不連續試驗」更名為「複合型非連續試驗」，沿用既有分類識別碼。

每個複合項目可儲存2～20個子試驗，提供新增、移除、上移及下移。每個子試驗各自設定名稱、最多12組試驗條件，以及從設備資料庫選取的適用設備。條件沿用共用規格參數、單位及「數值／正負差」；不同子試驗可重複使用同一種類，例如高溫與低溫各自設定溫度。單一子試驗內的條件及設備保持唯一。

子試驗使用固定識別碼保存順序與內容，排序時保留尚未儲存的數值。名稱不可空白或重複。試驗列表展開後，依序顯示各子試驗條件與設備；重新開啟編輯可繼續各別修改。管理視窗保留上方標題與關閉按鈕，內容區可捲動。

舊複合類型若只有一組條件，開啟時將原條件與設備帶入第一個子試驗，並提供第二個子試驗。明確儲存後才更新工作區資料。轉回單一試驗時，畫面先說明將保留第一個子試驗的條件與設備，確認後才移除其餘子試驗設定。既有單一試驗維持原編輯方式。

儲存沿用目錄管理權限、版本檢查、準備／提交及結果查詢交易。後端逐組核對種類、單位、條件範圍與工作區設備歸屬。規格參數使用量包含子試驗，仍被使用的種類及單位受到刪除保護。設備比對使用各子試驗完整容許範圍及適用設備清單，計畫核對會回報缺少合適設備的子試驗，並保留各組比對來源。

工時、日期規則與簽核流程沿用試驗項目原設定。既有委託、簽名及已保存計畫保留；這次新增的是試驗目錄的子試驗設定，並未回填既有案件的複合階段協定。
