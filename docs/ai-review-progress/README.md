# AI 委託單審查進度浮動視窗

點選審查視窗的「AI 審查」後，將原本嵌入資訊內容的跑條改為浮動視窗，沿用 AI 自動化排程的企業藍色圖示、進度條、步驟清單及按鈕樣式。

- 以原有5秒Demo查核展示顯示百分比與六項欄位檢查：產品代碼、產品類型、需求日期、測試數量、試驗規範／試驗手法、判定基準。
- 使用原生模態視窗與背景遮罩，鎖定背景互動，支援取消、Escape、結束後回到AI審查按鈕及深淺色／手機版。
- 完成後關閉進度視窗，於原資訊頁顯示既有結果；取消停止原計時器，不延遲補出結果。
- 保留既有規則、結果內容與簽核功能；進度明示為Demo展示，沒有真實AI API呼叫，不自動核准或改寫案件。

修改：`src/AiReviewProgress.jsx`、`src/AiReviewProgress.css`、`src/LmsApp.jsx`、`e2e/ai-review-progress.spec.js`。

Lint、Production Build、diff check通過；4項新增桌面／手機深淺色案例及6項既有LMS委託介面回歸，共10項通過。新增案例驗證查核進度、完成、取消、Escape、焦點還原、取消後計時器不殘留、視窗不超出螢幕，以及案件／帳號／排程資料前後不變。最後對比調整後4項新增案例重跑通過。本輪未重跑完整E2E與全套單元測試。
