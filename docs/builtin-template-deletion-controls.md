# 個別內建試驗參考範本與委託資訊控制項

「文件與報告設定」保留內建試驗參考範本區塊，具 `catalog.manage` 權限且可管理文件的使用者可逐筆刪除試驗參考範本。刪除前顯示範本名稱及確認視窗。這些參考 Excel 原本由試驗目錄即時產生；刪除會在目前工作區保存不可改寫的移除紀錄，讓重新登入、不同裝置及三系統範本瀏覽入口套用相同結果。

試驗定義、共用試驗參數、已上傳檔案、報告綁定、簽名及已送簽案件版本不變。空白委託單、空白報告單與上傳版本維持各自管理方式。開啟中的參考預覽會因刪除失效，下載產生前後亦查核移除紀錄，避免在非同步生成中途被刪除的參考仍被交付。

Migration 050 新增一張空的私有移除紀錄表、權限受限的刪除函式及目錄 metadata；不會替使用者刪除任何現有項目。資料表啟用 RLS，禁止 anon、authenticated、service_role 直接讀寫；僅透過帶工作區與使用者檢查的函式操作。刪除核對試驗修訂版，使用操作識別確保同一操作重送不會重複刪除／稽核，並沿用既有範本操作結果查詢。網路中斷時保留待查識別，確認結果前不自動再次送出。舊版目錄回傳的 trials、files、can_manage 保持原意，新增 hidden_builtin_template_ids 供新版畫面過濾。

委託資訊的查閱按鈕與右側狀態標籤統一為 32px 外框高度，查閱圖示為 21px，保持垂直中心一致且 hover 不位移。關閉元件使用單一 SVG，移除原本桌面文字 X 與手機 SVG 同時顯示的結構；角色編輯器也移除額外 CSS 偽元素 X。共用視窗關閉按鈕以 flex 水平、垂直置中，保留原有關閉、鍵盤、焦點返回及忙碌保護行為。

驗證涵蓋桌面、手機、320px 與深色模式；測試確認單筆移除、取消、跨三系統列表同步、唯讀權限、修訂衝突、結果不明時查回，以及查閱／狀態高度和關閉圖示中心點。資料庫測試僅在隔離無網路的本機合成資料執行，每一筆交易均回滾；原範本交付與空白範本功能另有回歸測試。
