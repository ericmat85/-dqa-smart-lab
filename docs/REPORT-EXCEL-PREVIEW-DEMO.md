# Excel 報告審核檢視

接續 `codex/report-archive-demo`，不改變九階狀態、簽核權限或 PDF 產生時點。

## 操作

- LMS 試驗委託列表：點**委託編號**開啟既有「委託單資訊」，包含試驗執行資訊、目前狀態、委託欄位及簽核流程；點**審核**才開啟報告審核視窗。
- 審核視窗直接顯示目前簽核 Excel 的所有可見工作表，可切換工作表、調整 50／75／100／125% 比例及在檢視區內捲動。
- 檢視合併儲存格、格式化數值、文字、PNG/JPEG 圖片及已轉印簽名。二階看到執行人員簽名，三階再看到二階已簽內容。
- 審核操作固定在視窗底部：關閉、退回報告、簽名並核准報告。核准須完成簽名，且目前版本的 Excel 已載入；版本變更時重新載入，不能沿用舊版本的檢視完成狀態。
- 「規則檢查與簽核歷程」收合在檢視區下方。依使用者更新要求移除簽核 Excel 下載按鈕及處理函式，保留唯讀檢視與結案 PDF 下載。
- 報告資料庫的委託編號也可開啟同一個委託資訊視窗，查詢已結案的試驗資訊與流程。

## 權限及 PDF

讀取 Excel 時重新取得當下帳號、案件及報告版本，依既有 `canReadReport` 規則判斷。停用、非案件關係人或非對應主管不能取得檢視資料。

檢視器只使用 Excel 內已儲存的數值及內嵌圖片，不執行公式、不追蹤外部連結，不修改工作簿，也不產生／保存 PDF。報告仍須依序完成二階、三階主管簽核，再由指定委託者主管確認查閱，才產生完整 PDF 並封存至本機 Demo 資料庫。

## 限制

此為瀏覽器唯讀檢視，不是 Microsoft Excel 引擎。原生圖表、部分浮動物件、頁首與頁尾可能無法完全還原；遇到不支援圖片或未計算公式時會提示，應下載 Excel 核對。隱藏工作表不自動顯示，會標明隱藏數量。所有可見工作表的資料範圍都可捲動查看，不只截取前幾列。

## 驗證

149 項程式測試通過；17 項瀏覽器 E2E 通過，另重跑一般性能審核及封存案例。驗證包含：工作表切換、合併格、時間／電壓精度、二／三階簽名、最後一列／欄可取得、底部操作在 1366×768／1440×900／1920×1080 可見、委託編號入口分流、封存資料庫的資訊連結，以及審核檢視不提前產生 PDF。

lint、build 成功，保留既有 4 項 lint 警告及大型 chunk 警告。已檢視實際瀏覽器截圖；不以測試通過宣稱未支援的原生 Excel 物件完整。
