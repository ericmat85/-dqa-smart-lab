# 工作區預設範本綁定

在「文件與報告設定」新增工作區預設範本，可選擇任何已保存的空白委託單版本，或切回系統內建空白委託單。上傳、版本列表與預設綁定整合於同一張「空白電子委託單」功能卡。列表標記目前預設版本，提供預覽及「委託資訊代入自動化」；原稿下載統一由三系統的資料庫提供。

這項綁定決定三系統資料庫「通用文件 → 工作區預設委託單」所提供的空白原稿。下載為指定上傳版本的原始檔，保留檔名、版本、格式與bytes；不是重新產生內建Excel。欄位對應及填入規則見[資訊代入與儲存格對應](../workspace-document-cell-mapping/README.md)。設定只影響後續送簽，不更換已提交案件、簽核報告或既有結案PDF的版型。

綁定使用工作區、不可覆寫的範本ID及檔案SHA-256，不依檔名選取最新版本。上傳另一份同名檔案不會自動改綁。管理員可更改，唯讀使用者可查看及預覽；下載請由資料庫操作，無法更改綁定或代入設定。雲端設定保存在工作區資料庫，可重新登入或換裝置讀取；Demo使用既有IndexedDB設定交易。

042新增私有狀態欄位與複合外鍵、一個管理員RPC，並擴充原列表及刪除RPC。綁定、刪除使用同一工作區鎖；被綁定的上傳檔不可刪除，必須先改綁或切回內建範本。修訂衝突與同一操作識別的重試均受控；舊操作讀回不會撤銷較新的綁定。結果不明時只查詢同一操作，不自動再次寫入。

預覽／下載前重新核對目前綁定、權限、原檔雜湊與Excel結構，完成讀取後再核對綁定修訂，避免在更改預設的同時顯示錯誤原稿。目標不存在、錯誤分類或內容不符時明確失敗，不改用內建檔。更改綁定會使已開啟的預設範本預覽失效；個別版本預覽保留其原版本。

資料庫初始化繼續保留這份參考範本庫及綁定。SQL測試全部在隔離合成資料庫內回滾；瀏覽器使用API fixture及Demo資料，不對正式工作區設定綁定或上傳／刪除範本。042安裝只增加結構，既有上傳檔、設定、案件及其他函式會在安裝交易核對內容雜湊後保留。

驗收涵蓋保存／重讀、三系統預覽與原始下載、回復內建、唯讀權限、綁定刪除保護、同名版本不改綁、競態、過期修訂、跨工作區、操作重試、未知結果讀回及初始化保留。既有Excel縮放與無PDF範本預覽維持。
