# Demo 操作位置與細節檢查

## 發現及修正

1. 實驗室的試驗委託、操作歷程、資料庫仍使用外層絕對定位的 Demo 工具，容易擠到標題／內容，與設備、物料頁不一致。五頁統一改為主內容下方、靠左、正常文件流；不與右下 AI 助理重疊。
2. 委託者主管待簽核資訊頁的「DEMO 填寫」原本漂在資訊框外且為主要藍色按鈕，已移入標題操作列，與返回清單並排，改次要式樣；LMS 審查視窗原有 Demo 操作已位於標題列，保留。
3. 試驗加速器原本與主要業務按鈕同為藍底，調整為次要式樣，保留功能。
4. Demo 工具展開會改變觸發按鈕位置，且面板使用固定白底。改為觸發按鈕在上、工具內容在下，深淺色跟隨現有主題，操作按鈕固定間距及完整寬度。
5. Escape 關閉 Demo 面板時原本會繼續傳給外層頁面。改為只關閉工具並還原焦點，不離開資訊頁；新增 aria-controls 對應關係。

沒有修改主管簽核、取消、退回、重設確認或九階資料流程；沒有移除任何 Demo 功能。清除／重設仍需原本的明確確認。

## 驗證

Lint、Production Build、diff check 通過。共14項相關瀏覽器案例通過：6項新增位置檢查（1920／1366／390、深淺色）、6項既有實驗室儀表板回歸（1920／1600／1366、深淺色）、主管退回後核准、取消 Demo 重設保留資料。

新增檢查涵蓋五個實驗室頁面、展開寬度、觸發位置不跳動、AI 按鈕不重疊、Escape 焦點還原、主管資訊框內操作及不變更案件資料。手機窄螢幕不超出頁寬。本輪未重跑完整 E2E。
