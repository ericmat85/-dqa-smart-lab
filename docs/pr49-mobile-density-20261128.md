# 行動版排版與字體

900px 以下的三個工作區共用緊湊字級與間距，600px 以下再縮小標題；桌面及列印文件維持原樣。

- 手機主標題 18px、區塊標題 14px、內文 13px、說明 12px；平板主標題 20px。字級會跟隨介面設定的小／正常／大字體偏好。
- 輸入欄位保留至少 16px，避免 iOS 聚焦時自動放大；欄高調為 38px。一般功能按鈕沿用 32px，圖示與關閉操作保留原本的點按空間。
- 摘要卡約 60px 高、10px 間距，手機的單數最後一張卡橫跨整列。管理總覽主題框、管理功能卡與 AI 狀態摘要減少留白，保留狀態與圖示間隔。
- 委託單基本資料的短欄位並排，長內容、唯讀帳號資訊及簽名仍保留完整寬度。窄於 360px 且搭配大字體偏好時改回單欄。底部五步驟導覽不覆蓋輸入欄位。
- 列表維持各自的橫向捲動、分頁與操作欄；批次排程視窗的標題、卡片和工具列套用相同間距。

僅修改呈現樣式及相應瀏覽器驗證，不變更資料庫、排程、簽核、AI 呼叫或權限邏輯。
