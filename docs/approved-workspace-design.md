# 共用工作區介面設計（PR49）

適用 LMS、電子委託、實驗室與既有管理頁面。麵包屑背景 #DCE7F1，頁面背景 #E8EDF3；深色模式保留。標題下方的一般描述隱藏，操作警告、驗證訊息與財務定義保留。

主頁籤列預設為海軍藍色 #142D48，選取頁籤為白底，直角貼齊內容框，無粗底線或圖示。主頁籤與內層頁籤高度均為 42px，徽章垂直置中。內層頁籤保留原始顏色、邊界與底線，不套用海軍藍列。

表頭預設採霧藍灰 #D2DCE8，文字 #30465F，與淺灰頁面形成辨識。頁籤、表頭、搜尋與分隔線共用工作區配色；文字及搜尋提示的對比維持至少 4.5:1，深色模式自動調整亮度。搜尋聚焦與滑鼠指向不增加外框。

設備、物料、排程、試驗委託管理與資料庫的搜尋欄整合於主頁籤右方，窄螢幕換行；電子委託的簽核／查閱與案件列表，其搜尋與篩選入口位於頁籤列右方。篩選欄位、狀態卡、排序、分頁及鍵盤頁籤切換保留。移除「清除篩選」文字按鈕與獨立筆數列，仍可透過欄位與狀態卡重設條件。

排程群組卡片及依設備副標題，距左側與上側皆 20px，手機為 16px。已含主頁籤框的頁面不再包覆額外白框。

一般功能按鈕統一 36px，文字及圖示垂直置中；導覽、狀態卡與時間軸等結構性控制項維持原尺寸。操作欄只顯示圖示，以 title／aria-label 保留用途。設備資訊使用第二版試驗箱、物料資訊使用方塊加資訊符號，藍底白圖；刪除使用紅底垃圾桶。資訊圖示為 18px。

新增的「系統管理 → 介面設定 → 頁籤與列表配色」提供四組配色、兩個獨立色票／色碼、淺深色即時預覽與自動文字配色。調色、取消及還原預設均不直接寫入；按儲存才套用。原有字體、語言與分頁設定保留於目前瀏覽器，沿用原操作。

配色存入既有資料庫的 workspace_appearance_v1 設定，三系統共用；同工作區成員可讀、管理者可寫。增量 migration 036 只增加兩個設定函式，沒有改動既有業務資料或儲存偏好。介面儲存包含版本衝突與結果未知時的重新讀取處理；登出會清除前一個登入者的配色。

既有資料來源、角色、案件、排程、模型與寄信流程保持。截圖使用示意 API，沒有寫入正式案件或呼叫模型／寄信。私人 Preview 接既有共用後端，使用者自行儲存會寫入共用資料；保留 Vercel 保護。PR 尚未合併，正式站程式維持現有版本。
