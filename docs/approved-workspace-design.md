# 共用介面設計（PR48）

套用至 LMS、電子委託與實驗室既有頁面。上方麵包屑底色 #DCE7F1，頁面 #F4F7FB；深色模式保留。頁籤採海軍藍列、白色選取頁籤，不加粗底線。內容外框含頁籤、4px 圓角、無極細藍色外框。頁面標題下方的描述移除，操作警告與財務定義保留。

操作欄按鈕只顯示圖示，以 title／aria-label 保留用途；設備資訊使用第二版試驗箱、物料資訊使用方塊加資訊符號，藍底白圖；刪除為紅底垃圾桶。按鈕 40px、圖示 20px。新增、儲存等主要動作仍保留文字。委託搜尋篩選移至案件清單標題右側，取消獨立筆數列，原篩選行為保留。

財務沿用相同外框與圖示；資料來源、權限、儲存、回執、排程及既有業務流程不由樣式層改寫。
