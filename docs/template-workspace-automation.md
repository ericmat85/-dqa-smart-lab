# 範本綁定與資訊代入整合

「文件與報告設定」的空白電子委託單整合預設綁定、上傳／新增、版本列表與預覽。上傳成功後先選取新版本，再明確儲存預設綁定；單純上傳不會替換目前綁定。同名原稿仍以各自的不可變ID識別。

「委託資訊代入自動化」取代委託單下載位置；「試驗資訊代入自動化」取代報告列表及綁定視窗的下載位置。報告歷史版本須先綁定後才能設定。變更來源但尚未儲存時，該視窗的自動化按鈕停用。開啟前重新向後端讀取綁定，只有目前已綁定原稿能進入原有的獨立全視窗儲存格設定頁。

移除獨立的「資訊自動代入與儲存格對應」區塊。設定狀態顯示在各原稿旁，未知儲存結果仍以原操作查詢，不自動重送。系統內建空白委託單維持固定版型；需自訂對應時先綁定上傳原稿。

文件設定、報告綁定、內建參考範本及各自的預覽均不提供下載按鈕。三系統資料庫仍保留通用文件、上傳版本與報告原稿下載，下載內容保持原始bytes。唯讀帳號僅查閱預覽，無法上傳、綁定或設定代入。

桌面以同一張卡片管理委託單；手機自動換行排列操作，報告版本轉為精簡卡片，不產生頁面橫向捲動。此變更不增加API或資料庫結構，也不更改現有範本、綁定、對應或已送簽案件。驗證使用合成API fixtures；沒有對實際工作區進行上傳、改綁或刪除。
