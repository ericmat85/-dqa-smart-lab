# 文件範本列表與共用重新讀取

移除空白電子委託單標題列的綁定圖示與「新增空白委託單」按鈕，將上傳委託單範本靠右，與報告原稿上傳一致。綁定仍由各版本操作列的鏈結圖示開啟原浮動視窗；只上傳不會自動改綁。

委託單列表改為「委託單範本／版本、適用試驗、綁定狀態、操作」。名稱、版本與保存日期併入第一欄，委託單明示所有試驗共用；綁定及資訊代入數量放在狀態欄。報告列表保留對應試驗，兩張表的欄寬、操作位置及手機卡片一致。

上方只保留一個「重新讀取」，取代報告區原按鈕。一次平行讀取委託單庫、試驗報告綁定／版本、資訊代入目錄；等待期間停用重複刷新及列表操作。完成後各資料源的錯誤仍明確顯示，可再讀取；不顯示未經確認的成功訊息。唯讀帳號亦可重新讀取。刷新不更改範本、綁定、欄位對應，也不代替未知寫入結果的收據查詢。

兩類列表的刪除按鈕使用共用 danger 分類，避免被一般表格圖示的白底藍色規則覆蓋。紅底搭配白色垃圾桶，停用／確認／版本保護行為不變。手機將資訊整理為緊湊卡片，上傳仍靠右；保留原有預覽、資訊代入、綁定與刪除確認。

本次僅調整介面與讀取協調，沒有 API、schema 或實際業務資料變更。資料庫下載維持原流程；已安裝的遷移至051不得重播。

文件設定分為三個可獨立收合的區塊：「報告品牌設定」、「電子簽章設定」、「文件範本自動化編輯器」。品牌與簽章預設收合，編輯器預設展開；原表單保持掛載，因此收合／展開不清空未儲存輸入，也不重新讀取或寫入設定。摘要可用鍵盤操作；移除內部重複標題與多餘外框。簽章方式與憑證限制、個人電子簽名入口及品牌預覽功能維持原行為。

資訊代入目錄的回應若不完整，顯示讀取錯誤並停用設定入口，兩類範本列表仍可查閱；重新讀取成功後恢復。未擅自以空白資料認定已設定或改寫綁定。

本次通過 46 項桌面／手機瀏覽器案例，涵蓋 320px、390px、1280px、1920px 與深色模式，包含分批複測。驗證移除按鈕、上傳靠右、相同欄位、紅底垃圾桶、同步讀取／錯誤重試、資料不完整時的保護、三區收合及草稿保留、鍵盤操作，以及既有綁定、刪除、下載與電子簽章權限規則。Build、diff 通過；Lint 0 錯誤、105 個既有警告。此次未修改後端或 schema，未重跑 SQL；所有瀏覽器業務操作均為合成 API fixtures。
