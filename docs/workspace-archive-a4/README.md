# PR49：共用資料庫式樣與 A4 全螢幕預覽

LMS、電子委託與實驗室的資料庫使用相同的頁籤、搜尋及報告列表。移除電子委託／實驗室的獨立白底外框，表頭、字級、圖示操作與 LMS 對齊。搜尋預設收合，切換分類後亦收合；範本庫保留原內層頁籤及共用列表。手機列表在外框內橫向捲動，不擠壓七個欄位。

按「查看 PDF」會立即切換至佔滿視窗的閱讀畫面；以灰底襯托 A4 頁面、適合畫面，支援多頁捲動。右上方保留下載與關閉按鈕，也可用 Esc 關閉，並將焦點還給原按鈕。

PDF.js 與 Worker 在預覽時從本站載入，可見頁面才繪製，離開可見範圍釋放畫布。不使用瀏覽器 PDF 插件。內容直接取自原封存 PDF，保留原頁面比例、頁數及檔案位元組；不生成或覆蓋報告。既有下載權限、Excel 結構與 SHA-256 驗證沿用，讀取失敗不顯示檔案；關閉後的延遲回應不會再次打開預覽。
