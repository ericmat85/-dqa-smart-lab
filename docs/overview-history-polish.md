# 管理總覽、委託工具列與文件設定精修

系統管理總覽以單一主題底色、細邊框及內距包住標題、工作區主視覺與管理入口，與其他管理面板一致；手機保留較小的左右內距。

三系統共用委託資訊工具列改為靠右排列「狀態／版本、查閱委託單」，兩者間隔10px、同高32px。查閱按鈕使用白底藍色文件圖示，深色模式沿用主題底色；資訊區與前方通知保留12px距離。查閱、列印與下載權限維持原行為。

「報告流程歷程」更名為「報告歷程」，共用簽核歷程的邊框、圓角、內距與摘要字樣。結案下載按鈕精簡為「下載結案 PDF」；仍下載原本的委託單與報告合併文件，未修改產檔或下載流程。

文件範本自動化編輯器的「工作區共用」標記移到收合標題旁，窄螢幕允許換行。移除四步驟導引、舊Excel報告範本資訊表與其下方保存／合併規則說明；委託及報告原稿庫保留。兩庫的標題、說明、版本數量間距縮小，桌面上傳按鈕與說明底緣對齊，手機維持靠右且不溢出。重新讀取、預覽、資訊代入、綁定、刪除及三區收合功能均保留。

本次只修改前端UI；沒有API、schema或實際業務資料寫入。遷移至051已安裝，不重播。建置、Lint及瀏覽器檢查結果見本次驗證記錄；瀏覽器資料為合成fixtures。

31項不同瀏覽器案例通過，含桌面／手機320、390、1280、1920px與深色模式，覆蓋外框、工具列間距、兩種歷程樣式、精簡標籤、編輯器移除內容、標題／上傳對齊，以及既有階段顯示、簽名版本與收合草稿保留。兩項新測試初版使用錯誤的既有無障礙名稱，修正定位後複測通過。Build與diff通過，Lint 0錯誤、105個既有警告。
