## 可操作的新增功能

- 委託草稿編輯比對開啟時的快照；其他頁面已更新時拒絕覆寫。保留草稿、送簽、指定主管核准／退回、補件與重新送簽，以及九階主線及既有例外狀態。
- 除了申請人不得自審，會依審查歷程禁止同帳號改角色後跨階審核同一案件。退件重送可由原階級再次審查；同一帳號在技術審查二階與報告二階是同階，不是跨階。
- 可選 1～4 台不同實體設備。手動選主設備及附加設備，或由規則推薦選取足夠設備；不得只填台數卻未選足設備。
- 每台分配樣品數，不超過件數容量及可用空間（L）。空間是 Demo 容積限制，並不代表幾何尺寸、治具或安全間距已確認。設備管理可補登未知空間；不擅自替既有台帳填入值。
- 溫濕度上下限按設備規格驗證；未知試驗類型、缺乏可驗證規格或不相容設備不自動通過。
- 設備與執行人衝突含準備、清理時間（各 0～1440 分鐘）；日期仍以台灣日界線計算。設備在準備開始時保留，正常完成／提前完成後的清理期間仍占用，清理結束才釋放，結案不會跳過或卡住清理保留。
- 多台設備在占用、釋放、取消及甘特圖中依各實體設備處理；不支援同槽共用。
- 實驗室新增「建立已完成範例（假資料）」按鈕，可重複建立不覆寫既有案件的模擬案例，用來展示報告，不代表真實量測或各角色親自簽署。
- 報告：已完成 → 提交 → 待審核（二階／三階）→ 待查閱 → 已結案。支援主管填原因退回至已完成，再修訂重送；保留版次、退回原因、審核人與歷程。
- 上傳簡化 XLSX 時保留原始檔，轉印作成人圖片簽名與上傳當日日期。報告簽名由左到右為三階（承認）、二階（確認）、執行人（作成）；三個位置須同列且不能重疊。
- 指定委託者主管確認查閱後，產生委託 PDF 與報告 PDF，再依「委託單 → 試驗報告」合併、封存及下載。封存的分段資訊可檢查頁次順序。

## 五分鐘報告展示

1. 進入實驗室，以 `chen@example.com` / `demo1234` 登入。
2. 點「建立已完成範例（假資料）」。清單出現已完成的 Demo 案件。
3. 點「提交報告」→「DEMO 填入」，等檔名和簽名出現後「提交」。檔案準備好前不能送出。
4. LMS 以 `level2@example.com` / `demo1234` 登入，在試驗委託清單「審核」報告。可先填原因退回，回實驗室修訂重送，再由二階核准。
5. LMS 以 `level3@example.com` 核准三階；每階都須簽名，等儲存完成再切換角色。
6. 電子委託以 `supervisor@example.com` 的「主管登入」查看該案，點「確認查閱並封存」。
7. 下載「結案 PDF（委託單＋報告）」，核對委託在前、報告在後及三方簽名。

新委託到排程接收的現場操作仍可依 `DEMO-2026-11-06.md` 執行。報告範例使用明確標示的模擬完成時間，不需要改電腦時間或等待真實試驗天數。

## 限制，不能宣稱正式完成

- 圖片簽名沒有憑證、可信時間戳、不可否認性或防竄改效力；不是正式電子簽章。
- PDF 和 XLSX 是簡化 Demo 版型。沒有宣稱與上傳的正式一般性能範本逐格一致；通常試驗正式範本仍待補。版型名稱依一般性能／其他試驗區分，但尚未完成正式專用欄位規則。
- 目前展示合併不含附件；若來源帶有 attachments 會阻擋，避免靜默遺漏。模穴評價關聯表／RD 規範圖等選配附件的上傳、轉換及插入順序待實作。
- 中文 OTF 的子集嵌入曾導致實際檢視器漏畫中文字，已改完整嵌入並重新渲染檢查。PDF 約 27 MB，仍需後續字型及共用資源最佳化；不要以文字可抽取或檔頭正確代替版面驗收。
- 原有本機封存可讀取；舊報告不會自動重製為新結案版型，已封存舊檔仍為原檔。
- 排程容積、溫濕度是可輸入的 Demo 檢查，未解析自由文字規範，也不涵蓋尺寸方向、治具、全部電性條件或全局最佳化。中斷／取消後的清理作業仍需人工安排。
- 沒有正式認證、後端交易、跨裝置同步或不可竄改稽核。資料仍在 localStorage／IndexedDB，使用者可修改。
- 生產分塊大小警告及原有 RequestApp 的 4 個 react/purity 警告保留，沒有關閉檢查或放寬門檻。

## 驗證方式

```sh
npm ci
npm run lint
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

雲端已有 Chromium 時：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/lib/chromium/chromium npm run test:e2e
```

E2E 每案使用獨立 context 與虛構資料；包含第一階段全部互動案例，以及報告退回重送／簽署／下載、雙設備空間與時間設定、舊草稿防覆寫。報告流程由畫面按鈕建立已完成案例，再走實際表單、IndexedDB 儲存與下載，不以測試替身取代報告保存。
