# PR49：品牌、個人圖片與緊湊介面

本次沿用 PR49。頁首操作按鈕統一為 32px；系統管理頁籤與麵包屑上側列保留 12px 間距。所有列表搜尋與篩選預設收合，新增成本的來源搜尋及專案試驗選取搜尋也預設收合。側邊欄移除 Demo 使用說明。

管理總覽移除外層白底、縮小分類卡片並刪除指定說明。其他管理分類保留白色內容框。成本表單改為橫式分區：基本資料、試驗與工時、來源與歸屬；以紅色星號顯示必填欄位，金額與必要計價數值留空仍沿用原本未估規則。

## 使用入口

- 公司 Logo：系統管理 → 系統與資料設定 → 公司標誌與品牌。管理者可預覽、儲存、還原原標誌；三個系統共用工作區標誌。
- 大頭照：右上角個人帳號選單 → 個人設定 → 大頭照 → 儲存大頭照。
- 電子簽名：個人設定 → 開啟電子簽名設定。可手寫或上傳，明確儲存後才成為本帳號預設；簽核案件時仍須本人確認套用，不變更已簽署文件。

圖片存於共用資料庫，換裝置登入同帳號可讀取。上傳會在瀏覽器縮放並重新編碼；Logo／照片來源最多 2 MB，簽名來源沿用 1 MB，上傳後每張儲存上限 512 KiB。瀏覽器原有照片／簽名可由本人手動匯入，不會自動轉存。

## 資料與權限

Migration 039 新增私有圖片表及兩個受保護 RPC。個人圖片只能由伺服器認定的目前啟用成員讀寫，管理者亦無權讀取別人的個人預設簽名；共享 Logo 僅管理者可替換。禁止直接存取資料表、指定其他帳號、跨工作區存取或上傳 SVG／遠端網址。

儲存有修訂衝突保護；失去回應時禁止自動重送，需重新讀取確認。登出即移除個人圖片，延遲回應不能恢復前一個登入身份。稽核僅記錄異動欄位名稱，不複製圖片內容。移除圖片保留修訂號，防止舊版本覆蓋。

雲端 migration 039 已以單一交易套用並驗證：既有業務與私人資料列、既有函式與權限、public 定義均保持不變；沒有建立正式帳號的測試圖片。正式站前端不部署，PR49 不合併；私人預覽儲存設定會寫入共用資料庫。
