# PR49：管理介面、收合搜尋與上側列配色

這次沿用 PR49 更新。正式站前端不部署、不合併，預覽站使用既有工作區登入；使用者在預覽站儲存的工作區設定會寫入共用資料庫。

- 系統管理頁籤與白色內容外框貼齊，標題統一置中間距。帳號統計卡桌面縮為半寬靠左，手機保留可讀寬度。
- 列表搜尋以放大鏡按鈕展開，預設收合；Esc 只收合並保留條件，按鈕顯示已套用條件的提示。
- 報表頁移除空隙及列表前的範圍說明，範圍資訊保留在「資料來源與計算方式」中。
- 工作流程改為列表呈現。系統參數、備份管理、資料維護與 Demo 工具整併至「系統與資料設定」，沿用各自原有權限、儲存與回收確認流程。舊資料維護網址仍可進入。
- 財務表頭與其他列表統一高度、字級及貼齊方式。
- 介面設定新增麵包屑上側列底色，可預覽、取消、儲存；三個系統共用設定，深色模式與文字對比自動調整。

## 資料庫相容性

Migration `038_workspace_header_appearance.sql` 新增版本 2 配色讀寫函式，在同一筆工作區設定儲存 `headerColor`。版本 1 仍回傳原本兩個欄位，版本 1 的儲存會保留既存上側列顏色；版本 2 要求三個合法 HEX 色碼。兩版本共用修訂號、工作區隔離、管理權限及稽核。

上線前使用無網路、無對外連接埠的合成資料庫驗證。雲端套用以單一交易檢查既有遷移、函式來源、權限、所有業務資料列和非本次函式；檢查失敗會回滾。這次不修改正式帳號、案件、費用、AI 金鑰或模型用量。

回退前端時仍可使用版本 1 函式，無須刪除設定或移除欄位。若停用版本 2，先回退消費端再撤銷新函式執行權；保留相容的版本 1 函式與設定資料，避免遺失使用者已儲存的上側列顏色。

## 驗收範圍

瀏覽器畫面使用本機合成 API 資料，覆蓋桌面、手機及深淺色；測試不使用正式帳號、不寄信、不呼叫付費模型。部署後只進行匿名連線與保護檢查，登入後的正式資料流程仍由使用者以自己的帳號驗收。
