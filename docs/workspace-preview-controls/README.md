# PDF 縮放、全視窗範本及照片上傳

2026-11-25，PR49 延續更新，三系統使用共用預覽及個人設定元件。

- 結案 PDF 全視窗預覽新增縮小、放大、25%～200%比例選單及適合視窗。100% 以 A4 在96dpi的寬度呈現；放大時重新繪製可見頁面的畫布，可在預覽內左右及上下捲動。維持多頁、下載原封存檔、Esc關閉及焦點返回。縮放不重新生成或修改檔案，既有權限與雜湊驗證保留。
- Excel 範本預覽填滿整個應用程式視窗，固定標題與底部操作列，工作表區獨立捲動。保留工作表切換、圖片、原始Excel下載與唯讀限制。移除這個範本視窗內的PDF版面預覽按鈕、內嵌框與PDF轉換路徑；結案PDF閱讀及其他報告封存功能維持。
- 個人設定的大頭照欄位恢復原本76px圓形照片、上傳說明與「＋ 上傳照片」按鈕，隱藏原生檔案欄位。保留2MB檔案驗證、明確儲存、移除、取消、帳號資料庫儲存、衝突與未確認結果讀回，不退回瀏覽器本機儲存。公司標誌及預設簽名邏輯保留。
