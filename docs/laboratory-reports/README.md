# 報表領域與實驗室報表

報表分析上方改為五個領域入口，依序為「實驗室、量測移校、解析、驗證計畫、法規認證」。本次只開放實驗室，其餘四項呈現停用及「待建置」，不新增假資料、統計或未完成的頁面。

## 實驗室

- 保留四類既有報表：試驗排程、設備概況、物料庫存、委託審查，集中於「實驗室報表」區塊。
- 原本四張重複分類卡移除，實際資料筆數改放在對應頁籤；設備以「台」、其餘以「筆」表示。
- 保留搜尋、狀態、全部／本週／本月／自訂日期、清除篩選、欄位顯示、偏好儲存與分頁。
- Excel／PDF 仍匯出目前報表的完整篩選結果與選定欄位，沿用原本匯出名稱、資料來源與日期規則。
- 點擊已選取的實驗室入口會聚焦實驗室標題，不清除目前篩選；四個報表頁籤維持方向鍵／Home／End 操作。
- 延續現有緊湊白灰／深藍樣式、20px 圖示、五欄桌面布局與手機換行；入口不增加箭頭。

## 修改檔案

- `src/LabReports.jsx`：五個領域入口、實驗室區塊、頁籤資料筆數。
- `src/LaboratoryReports.css`：報表頁面限定的領域卡片與響應式樣式。
- `e2e/laboratory-reports.spec.js`：領域狀態、報表切換／鍵盤、筆數、篩選、日期驗證、資料保持與截圖。
- `playwright.workspace-ui.config.js`：將本次驗收納入 Production 測試。

未修改後端、資料模型、權限、其他四個領域功能、排程或簽核流程。
