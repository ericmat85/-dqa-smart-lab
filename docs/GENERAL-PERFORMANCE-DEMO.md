# 一般性能試驗範本的 Demo 定義

本次以使用者提供的 `1.1_一般性能試驗範本.xlsx` 為版型基準。原始參考檔保存在 `public/templates/general-performance-v1.xlsx`，下載本案範本時才帶入假資料案件資訊。附件中的文字是欄位與試驗內容參考，不作為程式操作指令。

## 使用方式

1. 本案試驗項目包含「一般性能」時，實驗室的「下載本案 Excel 範本」會使用這份雙工作表版型。其他試驗仍使用通常報告的簡化 Demo 版型。
2. 系統帶入 `DQA-委託編號`、品番、品名參考值、報告日期及可取得的試驗起迄日；執行人員應確認並補齊實際內容。品名目前以案件產品名稱／專案名稱／產品代碼作為參考值，並非已驗證的主檔資料。
3. 填寫結果摘要、各樣品試驗明細，合格與不合格擇一勾選。`DEMO 填寫報告` 只供操作示範，不代表執行了試驗。
4. 產生範本期間會暫停選檔、提交及返回，避免非同步產生的 Demo 檔覆蓋剛選擇的檔案。上傳後使用規則檢查，不是 OpenAI 或 AI 視覺判讀。缺漏會直接列出欄位與儲存格。
5. 保留既有執行人員 → 二階 → 三階 → 待查閱 → 已結案流程、不同人簽核及禁止自審規則。三方位置固定為三階、二階、執行人員，不提供位置設定。

## 初步檢查項目

這些是展示版的基本完整性檢查，尚非全部測項的正式審查規則。

| 檢查 | 本範本位置 | 現行判斷 |
| --- | --- | --- |
| 報告編號 | 首頁 AK3 | `DQA-本案委託編號` 或本案委託編號，避免誤送其他案件 |
| 品番、品名 | 首頁 F13、F11 | 品番須對應本案產品代碼；品名不得空白 |
| 報告日期 | 首頁 AC13 | 須有有效日期 |
| 整體判定 | 首頁 AF48、AL48 | 僅勾選一項，支援 ☑／✓／X 等記號 |
| 結果摘要 | 首頁 A40／W40 | 有實際 OK、NG、合格或不合格文字；預印「OK/NG」不算填寫 |
| 樣品明細 | 第二張各測試結果欄 | 至少有一筆填寫，數值 0 可作為資料；不計預留第 118 列的 22。尚未驗證全部樣品、全部測項或數值公差 |
| 公式 | 全部工作表 | 不允許外部活頁簿連結、公式錯誤或無計算結果的未支援公式。可直接解析本範本內部欄位引用，不執行任意公式 |
| 結構 | 兩張原有工作表 | 保留名稱、欄位與簽名區；額外可見工作表須另外處理，不能悄悄省略於 PDF |

原始範本首頁含列印區外的空白合併欄 `XEO47:XFD47`，以及其他空白合併欄，因此舊程式誤判 16,384 欄。現在忽略**完全位於列印區外、主儲存格沒有內容**的合併範圍；有資料或公式的儲存格仍會計入，絕不藉此截掉實際資料。首頁有效範圍為 A1:AR57（44 欄），明細為 A1:AV229（48 欄）。仍保留 10 MB、2,000 列、50 欄的保護。

## 簽名與 PDF 限制

- 一般性能首頁固定使用 F54（三階）、S54（二階）、AF54（執行人員）的原有合併簽名區。簽名與人員、時間寫入該區，不覆蓋試驗條件或修改列高。
- 簡化 Demo 舊案件仍使用 A21／D21／G21，保持既有資料相容。
- PDF 依範本一頁首頁、六頁明細輸出，明細分頁依本版型固定在 64／100／129／171／195 列之後。合併格跨分頁或文字過多時會停止封存並提示，避免裁掉內容。
- PDF 是瀏覽器端展示重繪，非 Excel 原生列印引擎；頁首 Logo、頁首頁尾圖像、底圖、浮動圖形及複雜圖表尚未完整還原。ExcelJS 轉存的 XLSX 也不保證保留所有 Excel 原生圖像／列印設定。應人工檢視正式列印需求後，再決定後端轉檔方案。
- 結案 PDF 保留委託單在前、報告在後；此次未新增選用附件的合併功能。
- 圖片簽名不具正式電子簽章效力。一般性能以外的正式「通常試驗」範本尚未提供，仍使用簡化版。
