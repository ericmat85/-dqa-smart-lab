# Excel 範本預覽縮放

共用的全視窗 Excel 範本預覽新增「縮小」「放大」與顯示比例選單。適用於 LMS、電子委託及實驗室資料庫，也包含系統管理中的已上傳空白委託單版本與試驗範本。

- 預設100%，可依25%級距調整至25%～200%，到達上下限時停用對應按鈕。
- 「適合視窗」依工作表原始尺寸與目前檢視區寬、高計算比例，完整顯示整張工作表；視窗尺寸或工作表改變時自動重新計算。自動比例可低於25%，最高200%。
- 工作表選擇與縮放控制在閱讀區上方，手機版分列顯示。大於視窗時可在工作表閱讀區上下及左右捲動，工具列與下載／關閉按鈕保持可見。
- 使用CSS版面縮放，同時縮放表格、文字與內嵌圖片，保留合併儲存格及圖片相對位置；不修改工作表模型與Excel原始bytes。
- 手動比例在切換工作表時保留；適合視窗模式隨工作表尺寸重算；關閉後重新開啟回到100%。保留Esc關閉與返回原按鈕焦點。
- 保留原始Excel下載、權限及完整性檢查；範本預覽不新增PDF功能。既有PDF預覽縮放及報告簽核功能保持原行為。

驗收涵蓋三系統、淺／深色、桌面／手機、百分比與按鈕上下限、放大後捲動、適合視窗及調整視窗大小、切換工作表、圖片寬高與位置同步縮放、原檔下載及關閉重開。已上傳版本另核對縮放前後下載bytes與原檔相同。

所有瀏覽器案例使用本機合成資料與API fixture。沒有正式資料庫寫入、沒有資料庫遷移、沒有提交使用者的Excel附檔。本次僅更新PR49及受保護的私人預覽，不合併或更新正式站。
